# T2 y T3 · Tarjeta de preguntas de cierre (21 nov)

Una conversación por privado con cada persona que pagó algo por el grupo.
Lee las preguntas tal cual. No preguntes qué opinan de la app ni sugieras respuestas.
Si dicen "no sé" o "nada", anótalo así y pasa a la siguiente.

**Pregunta 1 (T2):** "¿Pagaste algo por el grupo que no quedó en la app? ¿Qué fue y por qué no lo metiste?"

**Pregunta 2 (T3, solo a los acreedores del neto final):** "¿A quién le tuviste que escribir para que te pagara, y cuántas veces?"

| Persona | Fecha | P1: ¿qué gasto quedó por fuera? (qué, monto, cuota) | P1: razón, en sus palabras | P1: código (pena / olvido / "no valía la pena" / otro) | P2: a quién le escribió y cuántas veces (grupo / privado) |
|---|---|---|---|---|---|
| | | | | | |
| | | | | | |
| | | | | | |
| | | | | | |
| | | | | | |
| | | | | | |

**Codificar después**, no durante la conversación. Usa "pena" solo si la razón habla de
vergüenza, de no querer cobrar algo chico a un amigo o de "qué oso". Si no encaja en
ninguna categoría, usa "otro" y copia la frase.

Si alguien dice ahora "eso fue una invitación", pero no lo anunció antes del cierre, el
gasto **sí cuenta** en el total: codifícalo como "otro" y copia la frase. Solo se excluyen
las invitaciones que quedaron anotadas en la bitácora en el momento.

Los gastos que salgan de P1 pasan a la bitácora del T2. Las respuestas de P2 pasan
a la hoja de pares del T3.
